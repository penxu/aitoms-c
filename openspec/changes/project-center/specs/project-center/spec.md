# Project Center

## Purpose

把工作台的「项目」从行式列表升级为独立项目中心：卡片网格呈现项目，卡片自带真实预览图，支持收藏筛选，并在加载阶段用骨架屏保持布局稳定。

## ADDED Requirements

### Requirement: 项目卡片网格
系统 SHALL 在 `/projects` 以卡片网格展示项目，每张卡片包含预览区、项目名称、创建日期和操作菜单；卡片宽度随视口自适应，窄屏降为单列。

#### Scenario: 打开项目中心
- **WHEN** 用户从侧边栏点击「项目」
- **THEN** 进入 `/projects`，看到按创建时间倒序排列的卡片网格，侧边栏「项目」为选中态

#### Scenario: 卡片操作菜单
- **WHEN** 用户点击卡片上的「…」
- **THEN** 展开包含「打开项目 / 收藏 / 删除项目」的菜单，菜单不被卡片边框裁剪，点击空白处或按 Esc 关闭

### Requirement: 项目预览图
系统 SHALL 在卡片预览区展示项目真实页面；仅当项目服务正在运行且卡片进入视口时加载，用 `/p/{id}/` 等比缩略展示且不响应鼠标交互。

#### Scenario: 运行中的项目
- **WHEN** 项目服务在运行
- **THEN** 卡片显示该应用首页的缩略预览

#### Scenario: 未运行的项目
- **WHEN** 项目服务未运行或预览探测失败
- **THEN** 卡片显示占位封面并标注「未运行」，不得展示「服务未运行」错误页

### Requirement: 加载骨架屏
系统 SHALL 在项目列表加载期间渲染与真实卡片同构的骨架屏，并在 `prefers-reduced-motion` 下关闭扫光动画。

#### Scenario: 首屏加载
- **WHEN** 项目列表请求尚未返回
- **THEN** 显示与卡片数量、尺寸一致的骨架块，请求完成后原位替换为卡片，不产生明显布局跳动

### Requirement: 收藏与筛选
系统 SHALL 持久化项目收藏状态，并提供「全部 / 已收藏」筛选；收藏状态失败时回滚乐观更新并提示错误。

#### Scenario: 收藏项目
- **WHEN** 用户在卡片菜单点击「收藏」
- **THEN** 卡片出现收藏标记，「已收藏」页签计数加一，刷新页面后状态保持

#### Scenario: 已收藏为空
- **WHEN** 用户切换到「已收藏」且没有收藏项目
- **THEN** 展示说明如何在卡片菜单中收藏的空状态
