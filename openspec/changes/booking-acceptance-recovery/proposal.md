## Why
预约应用的验收失败混合了验收执行器与用例前置条件问题：浏览器和独立请求的会话行为不一致、注册后未等待结果就导航、非法长度样本实际合法，以及列表失败路径未实现。
## What Changes
让 API 验收在真实浏览器会话中执行并报告实际响应；明确异步操作成功断言与可定位控件契约；修复当前预约应用的列表加载/错误/重试及确定性验收前置条件。

### Modified Capabilities
- `generation-reliability`: 浏览器与 API 使用同一用户上下文，业务错误可重试。
## Impact
平台验收执行器与生成提示，以及当前预约项目源码和执行计划；保留认证保护和真实业务断言。
