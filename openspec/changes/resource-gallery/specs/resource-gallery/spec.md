# Resource Gallery

## Purpose

提供「别人发布过的应用」的浏览入口：用卡片网格展示应用预览，支持分类、排序与收藏，并能把喜欢的想法一键带回工作台。

## ADDED Requirements

### Requirement: 资源页浏览
系统 SHALL 在 `/resources` 展示应用卡片网格，每张卡片包含预览图、标题、作者和浏览量，并在侧边栏呈现选中态。

#### Scenario: 打开资源页
- **WHEN** 用户点击侧边栏「资源」
- **THEN** 进入 `/resources`，看到按最新优先排列的卡片网格

#### Scenario: 分类与排序
- **WHEN** 用户点击某个分类或切换「最新 / 最热」
- **THEN** 网格只保留该分类，并按创建时间或浏览量重新排序

### Requirement: 应用预览
系统 SHALL 为每条示例应用渲染首屏预览，预览不依赖外部图片或截图服务，且随卡片宽度等比缩放。

#### Scenario: 不同分类的卡片
- **WHEN** 网格同时展示网站、游戏、电商、看板等分类
- **THEN** 各卡片预览呈现与分类相符的版式与配色

### Requirement: 收藏
系统 SHALL 支持收藏/取消收藏，并在本地持久化；「已保存」开关只显示收藏项。

#### Scenario: 收藏后过滤
- **WHEN** 用户点击卡片书签并打开「已保存」
- **THEN** 仅显示已收藏卡片，刷新页面后收藏仍在

### Requirement: 复用为需求
系统 SHALL 允许点击卡片或模板，把对应需求带到工作台并预填输入框。

#### Scenario: 从资源页开始构建
- **WHEN** 用户点击任意卡片
- **THEN** 跳转 `/dashboard?q=<需求>`，工作台输入框已填入该需求
