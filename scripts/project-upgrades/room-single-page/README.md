# 已授权房间应用的单页迁移

适用项目：p_mwhm79h1fjqv1c。仅迁移这个已明确授权的房间应用，不批量覆盖其他项目。

files/ 中是实际补丁：保留原数据接口/SQLite schema/家具素材/画布/3D与属性编辑，实现轻量首页、本地新建弹窗、哈希工作区、列表局部刷新、重型编辑器动态加载与未保存保护。旧页面入口仍可打开相应工作区；同页切换没有新的服务端页面编译。首页只传最近3个项目及真实总数，完整列表按需请求。next.config.ts 中的公网IP白名单仅对应此项目的已授权入口，其他部署应使用自己的域名；平台HMR代理修正后内部来源为localhost。

apply.mjs 先读取全部目标文件并验证原始SHA256，存在外部修改时停止；新文件不得覆盖已有同名文件。通过现有项目文件接口写入，新版默认开发预览直接使用源码，full模式才固定原预览快照；新组件先写，根页面最后写，最后才请求重启开发预览。迁移不读取或写入业务数据库。响应错误会停止，不绕过mutation lease、不直接执行用户命令。原预览切换失败沿用平台回滚逻辑。

运行（在仓库根目录，使用你自己的平台地址）：

```sh
node scripts/project-upgrades/room-single-page/apply.mjs http://119.29.93.214:3000
```

线上变更执行结果与浏览器验收见 docs/single-page-generated-apps-2026-11-15.md。该补丁是该房间项目的定向改造，不是任意已有应用的通用自动迁移器。
