# 直接启动开发预览

用户已确认：生成代码和安装依赖后只启动一次开发服务，立即展示预览入口，让页面首次访问触发 Next dev 编译，不再前置临时服务/首页验收。保留必要类型检查、路径与执行隔离、同项目单进程约束、失败回滚。full 模式维持生产构建和验收。

默认 runner 核对进程身份并等待 loopback TCP 端口可连接，不主动 GET 首页或健康接口。TCP 就绪只代表服务已监听；报告和 UI 明确首页及健康访问未验证。进程启动失败仍返回真实输出，停止和取消仍清理已拥有的进程。默认验证不启动临时检查服务，不调用浏览器验收；切换由现有 runner 负责，启动失败恢复旧源码服务。

服务API持续提供限长脱敏日志，工作台首次iframe加载显示编译提示及可折叠日志，日志不阻塞页面。仅首次加载提示，不把iframe load事件当成业务验收。明确不能取消 Next 本身首次页面编译，也不承诺本次修改已解决服务器编译性能。
